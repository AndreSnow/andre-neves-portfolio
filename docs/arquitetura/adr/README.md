# Registros de decisão arquitetural

ADRs registram decisões relevantes, seu contexto, alternativas e consequências.
Depois de aceita, uma decisão não é reescrita para esconder sua evolução: uma
mudança relevante deve ser registrada por um novo ADR que substitua o anterior.

## Estados

- Proposta;
- Aceita;
- Rejeitada;
- Substituída.
